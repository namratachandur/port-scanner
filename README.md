# port-scanner

This is a simple network port scanner designed to scan target IP addresses or domain names for open TCP ports.
Built for network diagnostics, security auditing, and understanding low-level socket programming.

# Features
- Port Range Scanning: Scan single ports, custom ranges, or common standard ports.
- Multi-Threading: Accelerates scanning performance using concurrent threads.
- Error Handling: Robust timeout and connection handling for inactive or firewalled hosts.

# Prerequisites
- Python 3.x installed on your system.
- Standard Python libraries used (`socket`, `sys`, `threading`, `concurrent.futures`).
